# Ossido with Tailwind CSS starter

## Install the Ossido CLI

**macOS / Linux**

```sh
curl -fsSL https://ossido.dev/install.sh | bash
```

**Windows**

```powershell
irm https://ossido.dev/install.ps1 | iex
```

## Create a project

This is the starter project for using Ossido and Tailwind CSS. To download it run in your terminal:

```sh
ossido new ossido-with-tailwind --template with-tailwind
```

To learn about how to set this up yourself, read our [Tailwind CSS documentation page](https://ossido.dev/documentation/styles/tailwind-css).
